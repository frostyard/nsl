# Security Policy

## Supported versions

nsl is pre-release and has no supported release series yet. Only the latest
release gets fixes; a fix ships in the next release from `main`.

The signed image catalogue is published weekly. A fix to an image or to the
catalogue ships in the next weekly publication.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
https://github.com/frostyard/nsl/security

Open the Security tab and click **Report a vulnerability**.

Do not open a public issue with the details of a vulnerability. Do not post
credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit.
- The impact: what an attacker can do.
- The steps to reproduce it.
